# NLP — Natural Language Processing

A collection of projects applying Natural Language Processing techniques using Python and Jupyter Notebooks.

## Projects

### Hotel Review Analysis (`hotel_review_analysis.ipynb`)
Extracts the most relevant collocations from hotel guest reviews to explain ratings and identify patterns in customer feedback.

### Text Representation Models

| Notebook | Description |
|---|---|
| `bag_of_words.ipynb` | Bag of Words (BoW) model for text vectorization |
| `tf_idf.ipynb` | TF-IDF weighting for document relevance |
| `cbow.ipynb` | Continuous Bag of Words (CBOW) with Word2Vec |
| `glove.ipynb` | GloVe — Global Vectors for Word Representation |
| `word2vec.ipynb` | Word2Vec embeddings for semantic similarity |

## Technologies

- **Language:** Python 3
- **Libraries:** NLTK, Gensim, scikit-learn, pandas, numpy, matplotlib
- **Tools:** Jupyter Notebook

## Dataset

`asimov.txt` — Text corpus used for GloVe training and experimentation.

## How to Run

1. Install the required packages:
   ```bash
   pip install nltk gensim scikit-learn pandas numpy matplotlib
   ```
2. Open the desired notebook in Jupyter.
3. Run all cells sequentially.
