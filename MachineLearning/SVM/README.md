# SVM — Support Vector Machine

A collection of projects applying Support Vector Machine classification using Python and R.

## Projects

### Multiclass Classification (`multiclass_classification/`)
Predicts credit card spending categories (3 classes) for customer segmentation using SVM with multi-class strategies.

**Highlights:**
- Exploratory Data Analysis (missing values, target balance, visualizations)
- Preprocessing: categorical encoding, imputation via PMM, target variable transformation
- SVM model training with hyperparameter tuning
- Model evaluation: accuracy, confusion matrix, classification report

### Mini Project (`mini_project/`)
End-to-end SVM mini project exercise from a Data Science course.

## Technologies

- **Language:** R, Python
- **Libraries:** e1071, caret, mice (R) / scikit-learn (Python)
- **Tools:** RStudio, Jupyter Notebook

## How to Run

1. Navigate to the desired subfolder.
2. Open the script or notebook.
3. Set your working directory and install required packages.
4. Run the script sequentially.
